# Airport Simulator

This monorepo contains two services which both need to be hosted to use the application.

- [Frontend Service (written using Next.js, Mantine, React)](/frontend/README.md)
- [Backend Service (written using Java, Spring Boot)](/backend/README.md)

### Purpose

This project was made for the group project in [CS261 Software Engineering](https://go.warwick.ac.uk/cs261) at the [University of Warwick](https://dcs.warwick.ac.uk) for Dorset Software.

The group consisted of
