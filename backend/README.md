# CS261 Software Engineering - Airport Simulator 

This is group 4's implementation of the Software Engineering coursework for 2025/2026 academic year.

## Frontend Service

### Running the frontend service

The frontend uses Next.js and Mantine. To run the server local, install nodejs and then run the following command, in the frontend directory, to start the service.

```bash
npm i && npm run dev
```


## Backend Service

## Running the backend service

The backend uses Spring boot and the maven dependency and package manager.
To run the server locally, install Java 21 and then run the following command, in the backend directory, to start the server.

```bash
./mvnw spring-boot:run
```

The backend server should now be accessible at https://localhost:8080/
